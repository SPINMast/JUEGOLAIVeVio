# JUEGOLAIVeVio
El proyecto trata de crear un videojuego web gratuito estilo Pac-Man con temática de Laive Bio / Yopi Mix y publicarlo en internet mediante GitHub Pages para que cualquier persona pueda jugarlo desde su celular o computadora sin descargar nada.
Puedes usarmi link del juego para qu lo pruebes y disfrutes de foma gratuita y libremente:
